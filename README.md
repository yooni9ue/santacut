# 🎅 산타컷 (SantaCut)

> 너 올해 산타컷 통과 가능?

친구들의 익명 평가로 착한 어린이 순위를 겨루고, 크리스마스 선물 수령 자격을 심사받는 연말 한정 랭킹 서비스입니다.

친구를 초대하고, 서로를 심사하고, 뒤집힌 순위를 공유하세요. 산타의 합격 커트라인을 두고 벌어지는 가벼운 경쟁을 키치한 크리스마스 감성과 장난스러운 밈으로 풀어냅니다.

## 서비스 흐름

1. **내 프로필 만들기** — 닉네임으로 산타의 심사에 참가합니다.
2. **친구 리그 만들기** — 초대 링크를 공유해 친구들을 모읍니다.
3. **익명으로 심사하기** — 세 가지 선택형 질문으로 친구를 평가합니다.
4. **내 순위 확인하기** — 착함 점수와 친구 리그 순위, 산타컷 통과 여부를 확인합니다.
5. **결과 공유하기** — 결과 카드를 공유하고 친구들에게 재심사를 요청합니다.

## 개발 예정 기능

| 우선순위 | 기능 | 설명 |
| --- | --- | --- |
| P0 | 프로필 | 닉네임 기반 참가 프로필 생성 |
| P0 | 친구 리그 | 리그 생성과 초대 링크 공유 |
| P0 | 익명 심사 | 선택형 평가와 중복 투표 방지 |
| P0 | 랭킹 | 평가 점수 집계와 리그 내 순위 표시 |
| P0 | 결과 카드 | 심사 결과 이미지 생성 및 공유 |
| P1 | 산타의 판결문 | 결과에 어울리는 장난스러운 심사평 |
| P1 | 재심사 청구 | 친구들에게 추가 평가 요청 |
| P2 | 시즌 결산 | 순위 변동 알림과 크리스마스 최종 결과 |

## 랭킹 운영 방향

- 전체 순위보다 친구끼리 참여하는 리그를 중심으로 구성합니다.
- 평가 점수는 0~100점으로 계산하고, 평가자당 같은 대상에게 한 표만 허용합니다.
- 최소 3명의 평가를 받은 뒤 공식 순위에 진입하며, 동점은 공동 순위로 처리합니다.
- 평가자 신원은 공개하지 않으며, 참여 동의·평가 취소·리그 탈퇴·신고 기능을 함께 고려합니다.
- 선물과 합격 여부는 재미를 위한 게임 설정입니다.

세부 점수 계산 방식과 합격 커트라인은 구현 과정에서 확정할 예정입니다.

## 디자인 방향

귀여운 2D 일러스트와 키치한 크리스마스 분위기, 친구끼리 웃으며 공유할 수 있는 밈을 지향합니다. 모바일에서 링크로 바로 참여하고, 결과를 SNS에 쉽게 공유할 수 있는 경험을 목표로 합니다.

## 프로젝트 상태

현재 기획 및 초기 설정 단계입니다. 위 기능은 개발 계획이며, 아직 실행 가능한 애플리케이션은 포함되어 있지 않습니다. 기술 스택과 실행 방법은 구현 후 안내합니다.
