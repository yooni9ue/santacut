# 크리스마스 리캡 카드

2026-11-21. 결과 리캡의 시각 디자인과 모바일 탐색 기준이다.

## 검토와 결정

UX·비주얼·타이포그래피·공유 이미지·모바일 접근성을 맡은 에이전트 5명이 현재 코드를 독립 검토했다. 주 담당자가 제안을 통합해 구현·검증했다.

- 큰 페이지 제목과 중첩된 패널을 줄이고, 메인에서 쓰는 굴뚝 산타를 공통 컴포넌트로 추출해 카드 하단에 배치한다.
- 메인·업로드와 같은 흰색·먹색·빨강과 겨울 회색, 기존 로컬 손글씨 서체를 쓴다. 서버 점수·문구를 그대로 유지한다.
- 카드 종류에 따라 종이 색과 내용 위계를 바꾼다. 손글씨는 제목과 판정 도장에만 사용하고, 편지·설명은 기본 고딕체 14~15px와 1.65~1.75 줄간격으로 읽기 쉽게 표시한다. 보조 정보는 11~13px와 진한 회색을 사용한다.
- 실제 응답의 7~8장을 현재 위치·진행 표시·전체 카드 목차·이전/다음·스와이프로 탐색한다.
- 같은 평가의 순위 갱신은 현재 카드 위치를 유지한다. PNG 생성은 글꼴과 일러스트 디코딩을 기다리고 출력 크기를 1080×1920으로 고정한다.

## 검증

모의 API 응답으로 모바일 Chromium·WebKit 38개 테스트를 통과했다. 8번째 카드 이동, 320px 화면의 긴 편지와 일러스트 배치, PNG 크기를 포함한다. 실제 Instagram·카카오톡 앱의 게시·전송 완료는 별도 기기 확인이 필요하다.

## 공개 링크 공유

카드 조작 아래에 「링크 공유하기」를 배치한다. 순위 확정 후 사용자가 누를 때만 기존 `/shares` API로 공개 결과 요약 링크를 만든다(`include_quote: false`). 현재 카드 전체를 공개하는 링크는 아니다. 시스템 공유창을 우선 사용하고 미지원·실패 시 클립보드로 복사하며, 복사가 막히면 직접 선택할 URL을 표시한다. 같은 평가에서는 만든 링크를 재사용한다.

## 이미지 저장 범위

- 「현재 카드 저장」은 보고 있는 카드 한 장을 1080×1920 PNG로 저장한다.
- 「전체 N장 저장 (ZIP)」은 리캡의 모든 카드를 화면 순서대로 PNG로 만든 뒤 ZIP 하나로 저장한다. 조서는 별도이며 이 묶음에 포함하지 않는다.
- 시작할 때 선택한 「농담 빼고 보기」 상태를 전체 이미지에 동일하게 적용한다. 저장 중 카드 이동·문구 변경·중복 저장을 막고 진행 장수를 표시한다.
- 저장용 카드는 화면 밖에서 한 장씩 렌더링하므로 보고 있던 카드 위치를 유지한다. 실패 시 부분 ZIP을 내려받지 않고 재시도할 수 있다.
