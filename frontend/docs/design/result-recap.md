# 크리스마스 리캡 카드

2026-11-21. 결과 리캡의 시각 디자인과 모바일 탐색 기준이다. 2026-11-27에 백엔드 v9 덱에 맞춰 카드 구성을 바꿨다.

## 검토와 결정

UX·비주얼·타이포그래피·공유 이미지·모바일 접근성을 맡은 에이전트 5명이 현재 코드를 독립 검토했다. 주 담당자가 제안을 통합해 구현·검증했다.

- 큰 페이지 제목과 중첩된 패널을 줄이고, 메인에서 쓰는 굴뚝 산타를 공통 컴포넌트로 추출해 카드 하단에 배치한다.
- 메인·업로드와 같은 흰색·먹색·빨강과 겨울 회색, 기존 로컬 손글씨 서체를 쓴다. 서버 점수·문구를 그대로 유지한다.
- 카드 종류에 따라 종이 색과 내용 위계를 바꾼다. 손글씨는 큰 글자(판정·상 이름·구간 이름)에만 쓰고, 한 줄 설명은 기본 고딕체 14~15px와 1.5~1.6 줄간격으로 읽기 쉽게 표시한다. 보조 정보는 11~13px와 진한 회색을 사용한다.
- 실제 응답의 5~8장을 현재 위치·진행 표시·전체 카드 목차·이전/다음·스와이프로 탐색한다.
- 같은 평가의 순위 갱신은 현재 카드 위치를 유지한다. PNG 생성은 글꼴과 일러스트 디코딩을 기다리고 출력 크기를 1080×1920으로 고정한다.

## v9 덱 카드 구성

카드마다 큰 요소 하나와 짧은 한 줄만 둬서 3초 안에 읽히게 한다. 숫자와 문구는 서버 값을 그대로 찍고, 화면에서 숫자가 들어간 문장을 새로 만들지 않는다.

- 모든 카드 상단 바에 `전국 {rank}등 · 상위 {top_percent}%`를 둔다. 순위를 기다리는 동안(`ranking_pending: true`)에는 「순위 계산 중」을 보이고 `GET /v1/me/recap`을 약 3초마다 다시 부른다. `false`가 되면 다시 부르지 않는다. 「순위 집계 전」 문구는 쓰지 않는다.
- 상단 바 아래 빨간 키커로 카드 이름을 보인다. 「최종 판정」, 「산타컷 표」, 「선물 받는 이유 N」, 「점수 깎인 말 N」, 「살아남은 말」, 「결론」이다.
- `VERDICT`: 「착한 아이/나쁜 아이」를 가장 크게 쓰고 GIFT/COAL 배지, 구간 이름, 판정 한 줄, 점수·컷 거리·선물 도착 날짜 칩을 둔다.
- `CUTLINE`: 여섯 구간 표에서 내 칸만 빨간 테두리로 켜고 「나 {점수}점」을 찍는다. 55~64 칸 위에 「선물 컷 65」 점선을 긋고 아래에 구간 고정 문구를 둔다.
- `REASON`·`CUT`·`KEEP`: 본인 말풍선과 칩을 크게 두고 상 이름(`label`)과 한 줄을 둔다. `quote`가 `null`이면 말풍선 없이 칩을 크게 찍는다. `dim_tag`가 있으면 작은 검은 태그로 단다.
- `CONCLUSION`: 구간 이름을 가장 크게(선물 금색, 석탄 석탄색) 쓰고 `칭호 · 유형`, 대표 말풍선과 칩, 마지막 한 줄, 점수·컷·상위 %·유형 % 칩, 여섯 칸 띠, 친구 소환 문구, `#산타컷 #{band_tag}`를 차례로 둔다.
- 굴뚝 산타는 판정과 근거 카드에만 둔다. 표와 결론 카드는 내용이 많아 일러스트를 뺀다.
- 「농담 빼고 보기」 토글은 없다. 공유 문구는 `share_text` 하나다. 모르는 카드 종류는 건너뛰고 나머지를 그린다.

## 검증

2026-11-21에는 모의 API 응답으로 모바일 Chromium·WebKit 38개 테스트를 통과했다. 2026-11-27에 v9 덱을 반영하면서 e2e 테스트를 새 카드에 맞췄다. 8번째 카드 이동, 320px 화면의 표·근거·결론 카드 배치, 순위 대기 재조회, PNG 크기를 본다. 카드별 렌더링과 재조회 간격은 단위 테스트로 확인한다. 실제 Instagram·카카오톡 앱의 게시·전송 완료는 별도 기기 확인이 필요하다.

## 공개 링크 공유

카드 조작 아래에 「링크 공유하기」를 배치한다. 순위 확정 후 사용자가 누를 때만 기존 `/shares` API로 공개 링크를 만든다(`include_quote: false`). 서버 공개 페이지는 링크를 가진 누구에게나 리캡 카드 전체를 보여 주므로, 버튼 아래에 「링크를 받은 사람은 누구나 리캡 카드를 모두 볼 수 있어요.」를 표시한다. 시스템 공유창을 우선 사용하고 미지원·실패 시 클립보드로 복사하며, 복사가 막히면 직접 선택할 URL을 표시한다. 같은 평가에서는 만든 링크를 재사용한다.

## 이미지 저장 범위

- 「현재 카드 저장」은 보고 있는 카드 한 장을 1080×1920 PNG로 저장한다.
- 「전체 N장 개별 저장」은 리캡의 모든 카드를 화면 순서대로 각각 PNG 파일로 내려받는다. 브라우저의 다중 파일 다운로드 허용이 필요할 수 있다. 조서는 별도이며 포함하지 않는다.
- 저장 중 카드 이동과 중복 저장을 막고 진행 장수를 표시한다. 저장 이미지도 화면과 같은 v9 카드를 그린다.
- 저장용 카드는 화면 밖에서 한 장씩 렌더링하므로 보고 있던 카드 위치를 유지한다. 실패 시 부분 ZIP을 내려받지 않고 재시도할 수 있다.

공유 링크와 이미지 URL은 응답의 `token`과 현재 웹 origin으로 만든다. 개발은 `dev.santacut.me/s/{token}`, 운영은 `santacut.me/s/{token}`이다. API 응답의 도메인이 `api-dev`여도 복사·공유에는 노출하지 않는다. `/s/**` 프록시를 통해 백엔드의 공개 페이지와 이미지를 제공한다.
