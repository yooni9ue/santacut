# 모바일 사용자 흐름 미리보기

현재 메인의 화이트·먹색·빨강 테마를 이어서, 가입·데이터 준비·심사·결과 흐름을 화면으로 확인할 수 있게 구성했다. 메인 시작 버튼은 `/start`로 연결된다.

| 경로 | 화면 |
| --- | --- |
| `/start` | 카카오톡·인스타그램 출처 선택 |
| `/prepare` | 출처별 기록 준비 안내 |
| `/upload` | 로컬 파일 선택, 파일명·크기·확장자 확인, 예시 파일 선택 |
| `/join` | 닉네임 형식 검사와 예시 지역 선택 |
| `/review` | 입력 요약과 미리보기 확인 |
| `/analysis` | 대기·심사 중·오류·근거 부족 상태 예시 |
| `/result` | 가상 점수·판정·도착일, 항목 펼쳐보기, 공유 카드 모달 |
| `/ranking` | 가상 순위와 더 보기 |

## 구현 범위

- 입력은 React Context 안에서만 유지한다. 새로고침하면 초기화된다.
- 선택한 파일은 내용을 읽거나 서버에 전송하지 않는다. 파일 형식·크기 확인은 로컬 파일 선택 UI의 예시이며 실제 파서 검증이 아니다.
- 닉네임 중복 조회, 실제 지역 데이터, 참가 등록, 업로드, AI 분석, 실제 순위·ETA, 공유 링크 발급은 연결하지 않았다.
- 결과·참가자·순위·도착일은 예시라고 화면에 표시한다. 심사 대기는 타이머로 실제 작업처럼 진행시키지 않는다.
- 카카오톡 화자·지역 목록은 화면 확인용 예시다. 실제 파일·지역 API 연결 시 교체한다.
- 준비 안내의 기기별 상세 경로는 검증 후 추가한다.

## 확인

`frontend/`에서 `pnpm build` 후 `CI=true pnpm test:e2e`로 프로덕션 UI를 확인한다. 모바일 Chromium·WebKit에서 흐름 입력 유지, 잘못된 파일·닉네임, 심사 오류, 공유 모달, 320px 폭을 검증한다.
