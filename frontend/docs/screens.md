# 모바일 화면과 실제 구현 범위

2026-11-27 develop 코드 기준이다. 메인 시작 버튼은 `/start`로 연결된다. API 연동은 코드 연결을 뜻하며 실제 AI 성공까지 검증했다는 의미는 아니다.

| 경로 | 실제 흐름 | 예시 흐름 |
| --- | --- | --- |
| `/start` | 출처 선택, 참가 정보 먼저 등록 링크 | 메인 판정 예시는 홈에서 제공 |
| `/prepare` | 출처별 준비 화면. 일부 문구는 아직 미리보기 기준 | 같은 화면 사용 |
| `/upload` | UTF-8 TXT/JSON, 20MB, 화자 추출 후 본인 선택. 전송 전 로컬 처리 | 파일 없이 예시로 둘러보기 |
| `/join` | 세션·지역·닉네임 가용성·참가 등록 API | 예시 닉네임·지역 입력 |
| `/review` | 두 동의 후 multipart 제출 | 미리보기 확인 |
| `/analysis` | GET 상태 확인 후 SSE 구독. 순위 반영 중에는 새 리캡을 먼저 표시하고 성공하면 `내 결과 보기` 버튼 표시 | 버튼으로 가상 상태 전환 |
| `/result` | 실제 점수·유형·순위·ETA, v9 리캡 덱(판정·산타컷 표·근거·결론 카드)과 조서 조회, PNG 공유/저장, 공개 링크 생성·복사. 순위 대기 중에는 리캡을 약 3초마다 다시 불러 상단 순위 바를 채운다 | 가상 결과·공유 모달 |
| `/ranking` | 랭킹 API, 내 결과, 커서 더 보기 | 가상 참가자 목록 |
| `/s/{token}` | rewrite를 통해 백엔드가 공개 HTML/PNG 제공 | 예시 공유 모달과 별개 |

## 상태 유지와 진입 규칙

`PreviewProvider`의 React Context에 출처·파일·화자·참가 화면 값·분석 ID와 `sample` 플래그가 있다. 새로고침하면 초기화된다. 세션은 서버 쿠키에 남지만 파일은 다시 골라야 한다. 참가 등록 화면은 `/me`로 복원한다.

- `sample=true`는 예시 선택에서 설정한다.
- `/result`, `/ranking` 직접 진입은 기본 `sample=false`이므로 실제 API를 조회한다.
- `/analysis`는 예시 선택에서만 가상 화면을 표시한다. 실제 흐름에서 작업 ID가 없으면 최근 작업을 조회해 새로고침 뒤에도 상태를 다시 확인한다.
- 실제 분석 성공 후 `내 결과 보기` 버튼으로 `/result`에 이동한다. 자동 이동은 하지 않는다.

## 확인된 구현 차이와 남은 작업

| 항목 | 현재 동작과 필요한 작업 |
| --- | --- |
| 전송 고지 | 상대 메시지도 AI 맥락에 포함하는 서버 정책을 동의 화면에 반영해야 한다. 본인만 채점하는 것과 본인만 전송하는 것은 다르다 |
| 최저 항목·근거 부족 | 현재 화면은 `weakest_dimension`에 근거 부족 표시를 붙인다. 실제 근거 부족은 `low_confidence_dimensions`로 판단해야 한다 |
| 순위 반영 대기 | 서버는 이전 스냅숏 점수·순위를 유지할 수 있다. 현재 새 점수 확정 문구는 이를 충분히 설명하지 못한다 |
| 랭킹 | `eta_date`는 타입만 있으며 날짜 표시 없음. `409 RANKING_SNAPSHOT_CHANGED` 시 첫 페이지 재조회 미구현. 더 보기 요청 잠금 필요 |
| 추가 결과 필드 | 배지·본인 인용·유형 비율·근거 부족 키는 화면 미반영. 상위 %는 항목 펼침 영역 안에 표시 |
| 공유 | 순위가 있으면 사용자가 공개 링크를 생성한다. 서버 PNG를 기기 공유 메뉴로 보내거나 저장하고, URL을 기기 공유 메뉴로 보내거나 복사한다. 새 리캡·조서는 화면 카드를 PNG로 저장하거나 기기 공유 메뉴에 넘긴다. 인라인 이미지 미리보기·공유 취소·인용 포함 토글·카카오 SDK 직접 공유는 미구현. 생성 요청은 JSON `include_quote: false`를 전송 |
| 계정 관리 | 지역 변경·데이터 삭제 API는 백엔드에 있지만 프론트 UI·클라이언트는 미구현 |
| 오류 복구 | 결과 없음은 별도 화면. 공유 생성 오류는 결과를 유지하고 공유 영역에 표시한다. 분석 첫 GET 실패·작업 없음 복구 안내 보강 필요 |
| 화면 라벨 | 실제 결과·랭킹·분석 일부가 기본 `FlowFrame`의 미리보기 문구를 사용한다. 안내 및 footer 정리 필요 |
| 파일 읽기 | 브라우저에서 최대 20MB 파일 전체를 읽는다. 스트리밍 파서는 프론트에 없음 |

이 차이는 문서 수정으로 구현 완료 처리하지 않는다. 후속 코드 작업은 [전체 점검 기록](../../docs/development/implementation-audit.md)에 정리한다.

## 확인 방법

`frontend/`에서 `pnpm build` 후 `CI=true pnpm test:e2e`를 실행한다. 참가 등록·동의 후 제출·결과 공유는 모의 API 브라우저 검증이며 실제 AI·랭킹·공유 통합 검증과 별개다. [파일 흐름](file-analysis-flow.md)과 [참가 등록](participant-registration.md)을 함께 참고한다.
