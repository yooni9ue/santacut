# 산타컷 디자인 방향

이 문서는 현재 메인 화면과 대화에서 채택한 시각 방향을 정리한다. 새로운 기능 요구사항이나 실제 AI 심사 결과를 정의하지 않는다. 화면·사용자 흐름은 [UI·UX 기획](../planning/ui-ux-plan.md), API 동작은 [연동 가이드](../api/frontend-api-guide.md)를 참고한다.

## 현재 방향

**화면은 간결하게, 산타의 표정과 문구는 엉뚱하게.** 모바일 웹을 기준으로 흰 배경과 먹색 타이포를 쓰고, 빨강으로 핵심 제목과 주요 행동을 강조한다. 노란 배경, 두꺼운 장난감 같은 그림자, 과도한 배지 장식은 현재 방향에서 사용하지 않는다.

| 항목 | 현재 기준 |
| --- | --- |
| 기본 배경 | 흰색 `#ffffff` |
| 주요 글자 | 먹색 `#242424` |
| 포인트 | 빨강 `#d9362b` |
| 보조 영역 | 옅은 회색 배경과 얇은 구분선 |
| 화면 폭 | 모바일을 우선하며 넓은 화면에서도 최대 480px 중심 배치 |
| 메인 제목 | 개구체 Bold. 반듯하지 않은 손글씨 느낌을 가장 큰 제목에 적용 |
| 본문·말풍선 | 기존 가독성 서체를 유지. 전체를 같은 손글씨로 바꾸지 않음 |
| 주요 행동 | 모바일 하단 고정 버튼과 safe area 여백 |

## 캐릭터와 톤

- 산타는 정면 상반신과 연결된 머리·어깨를 가진다. 배가 굴뚝에 끼어 양손으로 가장자리를 짚는 자세이며, 얼굴과 몸이 함께 움직인다.
- 유머는 색을 많이 넣거나 화면을 복잡하게 만드는 대신 문구, 표정, 작은 상호작용으로 만든다.
- 대표 문구는 `올해도 착한 척 했니?`, `괜찮아. 산타도 일하는 척해.`다.
- 예시 판정과 실제 분석 결과를 구분한다. 재미용 AI 해석과 배송 시뮬레이션이며 실제 선물은 배송하지 않는다.

## 시안 보존

| 경로 | 용도 |
| --- | --- |
| `/` | 현재 화이트·먹색·레드 메인 |
| `/classic` | 초기 우체국 시안 |
| `/original` | 순한맛 손그림 시안 |
| `/post-office` | 북극 심사국 시안 |

이전 시안은 비교용이다. 새 화면을 만들 때 현재 메인 기준과 이전 시안의 색상·서체를 섞지 않는다.
