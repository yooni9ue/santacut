# 코드 리뷰 기록: DDD·계층 구조

최종 구현을 대상으로 역할별 독립 리뷰를 진행했다. 이 기록은 AI 에이전트 리뷰 결과이며 사람 12명의 검토를 뜻하지 않는다.

## 확인 및 반영

- 분석 평가·작업 완료·랭킹 스냅샷 게시를 한 트랜잭션으로 묶었다.
- 완료 시각 하나를 평가, 작업, 랭킹 스냅샷에 함께 사용한다.
- 랭킹 조회는 JPA projection과 DB offset/limit을 사용한다.
- 취소된 공유 행을 제거하고 활성 공유가 참조하는 스냅샷만 보존한다.
- SSE는 예약 조회를 사용하고 연결이 종료되면 예약 작업을 취소한다.
- 영속성 접근은 Spring Data JPA로 통일했다.

## 남은 설계 개선

- 웹 컨트롤러, 응용 유스케이스, 도메인 규칙, 영속성 구현의 패키지 경계가 분명하지 않다.
- `AnalysisJobs`와 `ShareController`가 여러 변경 이유를 함께 가진다.
- 분석 상태가 문자열이고 일부 응답 계약이 `Map` 기반이다.
- 랭킹 재계산의 snapshot 정리 과정은 활성 공유와 snapshot 목록을 메모리로 조회한다.

이 항목들은 기능 검증과 별개로 남은 설계 부채다. 이번 리뷰에서는 품질 점수를 임의로 매기지 않았다.
